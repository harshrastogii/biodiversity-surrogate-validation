# Multiverse validation of open-data biodiversity surrogates (Northern Territory)

Code, data and manuscript for a study that compares five open-access spatial surrogates for
biodiversity with Northern Territory Government expert biodiversity-risk assessments, and tests
whether the answer to "which surrogate agrees best?" survives defensible changes to the analysis.

**Status (October 2026):** manuscript in preparation. The per-catchment results are final; pooled
estimates, intervals and cross-validated results are regenerated by the full run described below.

## What the study finds

Per catchment, using the committed data:

- Vegetation-type rarity (NVIS) agrees best per polygon in the three large BIORISK areas
  (Spearman's ρ = 0.24, 0.51 and 0.22) and best separates expert class ≥ 4 from the rest.
- Land-system rarity agrees better under area weighting in the Roper and at Larrimah, and better
  identifies the highest class (class 5) at Gunn Point and Greater Weddell (AUC 0.69 and 0.61
  against 0.46 and 0.47).
- The reversals have three causes:
  - **Small polygons.** 67–85% of polygons in the largest assessments are under 1 ha. Removing them
    lifts land-system rarity at Gunn Point from ρ = 0.14 to 0.29.
  - **A few rare vegetation groups.** The NVIS signal comes from rare groups that experts rate as
    sensitive. Without groups of rarity ≥ 0.25, Gunn Point falls from ρ = 0.22 to −0.04.
  - **Already-modified land.** Convertibility mostly identifies modified land. In the Roper its ρ
    falls from 0.21 to 0.02 without class 1.

## Reproducing the analysis

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# once, with the raw layers in place (see data/meta/P0_DATA_MANIFEST.md):
python scripts/harmonize.py          # -> data/processed/harmonized_{grid,polygon}.parquet
python scripts/export_centroids.py   # -> data/processed/polygon_centroids.parquet

# from here on the repository alone is enough:
python scripts/p3_confirmatory.py
python scripts/p3_blockboot.py
python scripts/p3_joint.py
python scripts/p4_revision.py        # 1-3 hours; seeds fixed
python scripts/make_tables.py        # -> paper/tables/
python scripts/make_figures.py       # -> paper/figures/ (Figure 1 also needs the raw geometries)
```

Reading the NVIS v7 raster geodatabase needs a GDAL build with the OpenFileGDB raster driver
(GDAL ≥ 3.7). Surrogate values are rounded to 4 decimal places on loading
(`config.load_polygons`), because area-weighted overlays leave floating-point residue that would
otherwise be ranked as real variation.

## Data sources and licensing

Inputs are open Northern Territory and Australian Government layers: *Mapping the Future*
biodiversity assessments, NT Land Systems, NT Land Use Mapping, NVIS v7, DEA Fractional Cover and
CAPAD. Full provenance is in `data/meta/P0_DATA_MANIFEST.md`. The raw layers keep their original
licences (CC BY or attribution) and are not redistributed here.

- Code (`scripts/`, `exploratory/*.py`): MIT, see `LICENSE`.

- Derived data (`data/processed/`): CC BY 4.0, with attribution to the upstream sources.
